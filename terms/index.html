利用規約

Flash（ホームページ制作・月額制）をご利用いただく条件です。お申し込みの前にお読みください。

第1条（この規約について）

この規約は、株式会社JOKER（以下「当方」）が「Flash」の名前で提供するホームページの制作・公開・運用のサービス（以下「本サービス」）を利用する条件を定めるものです。お申し込みの方（以下「お客様」）は、この規約に同意したうえでお申し込みください。

第2条（契約の成立）

  1. お客様が当方の決済ページでこの規約に同意し、初回分のお支払いが完了した時点で、契約が成立します。
  2. 当方は、お客様が第10条・第13条に当たる場合や、ホームページの内容が法令や公序良俗に反する場合は、お申し込みをお断りすることがあります。その場合、お支払いいただいた金額は全額返金します。

第3条（サービスの内容）

プランごとの内容は次のとおりです。

ライト月額 9,900円（税込）。6か月分の一括払いは 54,000円（税込）／1ページ・業種別のテンプレート／文章・写真の差し替え 月2回／公開まで最短即日
スタンダード月額 16,500円（税込）。6か月分の一括払いは 90,000円（税込）／6ページまで・テンプレートをお店に合わせて調整／文章・写真の差し替え 月5回／公開まで最短1週間
プレミアム月額 24,800円（税込）。6か月分の一括払いは 135,000円（税込）／10ページまで・ゼロから作る完全オリジナルデザイン／文章・写真の差し替え 月10回／公開まで最短3週間

全プラン共通で、スマホ対応、問い合わせフォーム（内容はお客様のメールに届きます）、公開までの設定一式、公開場所（サーバー）の用意を含みます。ご相談・修正のご依頼は LINE（またはメール）で受け付けます。

第4条（料金とお支払い）

  1. 料金は第3条のとおりです（税込）。初期費用はかかりません。
  2. お支払いはクレジットカードです。お支払いは「毎月払い」か「6か月分の一括払い」から選べます。初回分はお申し込みのときにお支払いいただき、以降は、毎月払いは毎月、一括払いは6か月ごとに、お申し込み日と同じ日に自動でお支払いとなります（その日がない月は月末）。
  3. 月の途中の開始・解約による日割り計算はしません。
  4. 決済ができなかった場合、当方からご連絡します。ご連絡から14日たってもお支払いがないときは、第11条により公開を停止することがあります。

第5条（制作と公開）

  1. お客様は、ホームページに載せる写真・文章などの素材を当方にお送りください。
  2. 公開までの目安は、素材がそろってから第3条の日数です。ご依頼が重なったときや、修正のやり取りが多いときは延びることがあります。
  3. 当方の都合で、お申し込みから60日以内に公開できなかった場合、お客様は契約を解除でき、当方はお支払い済みの料金を全額返金します。

第6条（公開後の修正）

  1. 文章・写真の差し替えやお知らせの追加は、第3条の回数まで月額料金に含まれます。1回の依頼にまとめていただいた分を1回と数えます。使わなかった回数は翌月に繰り越せません。
  2. ページの追加、デザインの大きな変更、写真の撮影、ロゴの制作は月額料金に含まれません。ご希望の場合は、内容と費用を先にお伝えし、ご了承いただいてから行います。

第7条（解約）

  1. 最低契約期間は、お申し込みの日から6か月です。
  2. 解約するときは、次回のお支払い日の前日までに、LINE またはメールでご連絡ください。お支払い済みの期間が終わったところで解約となり、それ以降の料金はかかりません。
  3. 最低契約期間（6か月）より前に解約する場合は、6か月に足りない月の月額料金を、解約のご連絡のあとにまとめてお支払いいただき、6か月目の終わりまで公開したうえで解約となります（例：ライトプランを2か月で解約する場合、残り4か月分の39,600円）。6か月分の一括払いの方に追加のお支払いはありません。
  4. 解約後は、ホームページの公開を停止し、当方が用意した公開データを削除します。ただし、第9条第3項によりデータをお渡しする場合を除きます。

第8条（返金）

お支払い後の返金はいたしません。ただし、第2条第2項・第5条第3項の場合と、当方の責任でサービスを提供できなかった場合は除きます。

第9条（素材と権利）

  1. お客様からお送りいただいた写真・文章・ロゴなどの権利はお客様にあります。お客様は、それらが他人の権利（著作権・肖像権など）を侵害しないことを確認したうえでお送りください。
  2. 当方が作ったデザイン・プログラム・テンプレートの権利は当方にあります。契約期間中、お客様はご自分のホームページとして自由にお使いいただけます。
  3. 36か月以上続けてご利用いただいたお客様には、ご希望により、解約のときにホームページの公開データ（HTML・画像など）を無償でお渡しします。お渡ししたデータは、そのホームページとして引き続きお使いいただけます。別の公開場所への移し替えや、ドメインの手続きの作業は含みません。
  4. 当方は、制作したホームページを制作実績として紹介することがあります。ご希望でない場合はお申し出ください。

第10条（禁止事項）

お客様は、本サービスで次のことをしてはいけません。

  • 法令や公序良俗に反する内容の掲載
  • 他人の著作権・商標・肖像権などを侵害する内容の掲載
  • 事実と違う、または誤解を招く表示
  • 当方や第三者に不利益・迷惑を与える行為

第11条（公開の停止と契約の解除）

お客様が第4条第4項・第10条・第13条に当たる場合、当方は事前の連絡なくホームページの公開を停止し、または契約を解除できます。
